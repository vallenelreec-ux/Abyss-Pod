# Abyss Pod — البقاء والعمق تحت الأرض

لعبة بقاء وتنقيب ثلاثية الأبعاد مبنية على **Godot 4** بلغة **GDScript**.

> الوثيقة المرجعية: وثيقة تصميم اللعبة (GDD) الإصدار 1.0.

## حالة التنفيذ

| المرحلة | الوصف | الحالة |
|---------|-------|--------|
| 1 | حركة اللاعب (WASD + الماوس) وبناء الغرفة (Pod) | ✅ منجزة |
| 2 | نظام الحفر (تقليل صحة الجدار وتدميره) | ✅ منجزة |
| 3 | نظام الحقيبة (16 خانة) | ⬜ قادمة |
| 4 | توليد الغرف العشوائية (RNG) | ⬜ قادمة |
| 5 | الوحوش ونظام القتال | ⬜ قادمة |
| 6 | واجهة المستخدم الكاملة ونظام البقاء | ⬜ قادمة |

## ما المنجز حالياً

- **اللاعب (`Player.tscn` + `player.gd`):** حركة WASD، نظرة الماوس، قفز، جاذبية، وشعلة إضاءة.
- **الغرفة الآمنة (`Pod.tscn` + `pod.gd`):** غرفة 2×2×2 متر تحتوي صندوق تخزين، طاولة صياغة، باباً محصناً، وخزان ماء يعيد التعبئة عند الاقتراب منه (حل مؤقت حتى نظام المخزون).
- **نظام الحفر (`digging.gd` + `wall.gd`):**
  - الجدران نقاط صحة 50 HP، والفأس الخشبي يسبب 10 ضرر لكل ضربة (5 ضربات للكسر).
  - صوت الضربة يختلف حسب ما خلف الجدار: صخر، معدن، فراغ، أو ماء.
  - الحفر يستهلك الماء: 1% لكل 5 ضربات.
  - عند نفاد الماء يفقد اللاعب 5 نقاط صحة كل ثانية، وعند الموت يعود للغرفة الآمنة.
- **الواجهة (`HUD.tscn` + `hud.gd`):** شريط الصحة والماء أعلى اليسار، مؤشر تصويب في الوسط، ومؤشر الطبقة والعمق أعلى اليمين.
- **الأداء:** الجدران مبنية بـ CSG مع مجسّمات تصادم ثابتة مناسبة لمرحلة التطوير.

## التحكم

| الإجراء | الزر |
|---------|------|
| الحركة | W / A / S / D |
| القفز | مسافة |
| الحفر / الضرب | زر الفأرة الأيسر |
| تحرير/التقاط الماوس | Esc / نقرة فأرة |

## التشغيل

1. ثبّت [Godot 4.2+](https://godotengine.org/download) (النسخة القياسية).
2. افتح Godot ثم `Import` واختر ملف `project.godot`.
3. اضغط `F5` للتشغيل.

## بنية المشروع

```
project.godot
icon.svg
scenes/

  Wall.tscn    جدار قابل للتدمير

  pod.gd       منطق الغرفة الآمنة
  hud.gd       الواجهة
  main.gd      ربط الإشارات
  hit_sound.gd توليد أصوات الضربات
```
